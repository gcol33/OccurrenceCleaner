# Test: equal coordinates

Flags records whose absolute longitude equals their absolute latitude,
the result of one value being entered in both fields.

## Usage

``` r
clean_equal(x, ...)
```

## Arguments

- x:

  A data frame of occurrence records.

- ...:

  Further arguments to
  [`flag_occurrences()`](https://gillescolling.com/OccurrenceCleaner/reference/flag_occurrences.md):
  `columns`, `reference`, `gazetteers`, `land_scale`.

## Value

`clean_<test>()`: the rows of `x` the test does not flag, with the
columns of `x` unchanged. See
[`keep_unflagged()`](https://gillescolling.com/OccurrenceCleaner/reference/keep_unflagged.md),
Cleaning functions.

## Fields

`lon`, `lat`.

## CoordinateCleaner

Equivalent to `cc_equ()` with its default `test = "absolute"`; identical
flags.

## Examples

``` r
x <- data.frame(decimalLongitude = c(10, -10, 10.0001), decimalLatitude = 10)
flag_occurrences(x, tests = "equal")$flag_equal
clean_equal(x)
```
