# Test: GBIF headquarters

Flags records within 1 km of the GBIF secretariat in Copenhagen (12.58
E, 55.67 N), a location some records receive as a default.

## Usage

``` r
clean_gbif_headquarters(x, buffer = 1000, ...)
```

## Arguments

- x:

  A data frame of occurrence records.

- buffer:

  Buffer distance of the test, in the unit of its Buffer section; the
  default is the test's default buffer.

- ...:

  Further arguments to
  [`flag_occurrences()`](https://gillescolling.com/OccurrenceCleaner/reference/flag_occurrences.md):
  `columns`, `reference`, `gazetteers`, `land_scale`.

## Value

`clean_<test>()`: the rows of `x` the test does not flag, with the
columns of `x` unchanged. See
[`keep_unflagged()`](https://gillescolling.com/OccurrenceCleaner/reference/keep_unflagged.md),
Cleaning functions.

## Fields

`lon`, `lat`.

## Buffer

`buffers = list(gbif_headquarters = 1000)`, in metres.

## CoordinateCleaner

Equivalent to `cc_gbif()`; same point, 72-gon buffer within 0.95 m of
the 1 km circle. The point lies outside the 1:50 million Natural Earth
coast, so it also fails `sea` at `land_scale = 50` and
`country_mismatch` with code `"DK"`, in both packages.

## Custom gazetteer

`gazetteers = list(gbif_headquarters = points)`, a data frame of
longitude and latitude; see
[`flag_occurrences()`](https://gillescolling.com/OccurrenceCleaner/reference/flag_occurrences.md).

## Examples

``` r
x <- data.frame(decimalLongitude = c(12.58, 12.6), decimalLatitude = c(55.67, 55.7))
flag_occurrences(x, tests = "gbif_headquarters")$flag_gbif_headquarters
clean_gbif_headquarters(x)
```
