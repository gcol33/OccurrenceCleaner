# Tests: basis of record

`basis_fossil` flags records with `basisOfRecord` `FOSSIL_SPECIMEN`,
`basis_living` those with `LIVING_SPECIMEN` (botanic garden, zoo and
culture-collection individuals). Matching ignores case and surrounding
spaces.

## Usage

``` r
clean_basis_fossil(x, ...)

clean_basis_living(x, ...)
```

## Arguments

- x:

  A data frame of occurrence records.

- ...:

  Further arguments to
  [`flag_occurrences()`](https://gillescolling.com/OccurrenceCleaner/reference/flag_occurrences.md):
  `columns`, `reference`, `gazetteers`, `land_scale`.

## Value

`clean_<test>()`: the rows of `x` the test does not flag, with the
columns of `x` unchanged. See
[`keep_unflagged()`](https://gillescolling.com/OccurrenceCleaner/reference/keep_unflagged.md),
Cleaning functions.

## Fields

`basis`.

## CoordinateCleaner

No equivalent; additions of this package.
[CoordinateCleaner](https://ropensci.github.io/CoordinateCleaner/)'s
fossil tests (`cf_*()`) test fossil ages and ranges, which this package
does not.

## Examples

``` r
x <- data.frame(basisOfRecord = c("HUMAN_OBSERVATION", "LIVING_SPECIMEN", "FOSSIL_SPECIMEN"))
f <- flag_occurrences(x, tests = c("basis_fossil", "basis_living"))
f[, c("flag_basis_fossil", "flag_basis_living")]
clean_basis_living(x)
```
